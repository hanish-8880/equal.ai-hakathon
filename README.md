# Chinku — tell it what you need, and it gets it done

**Equal AI × OpenAI Builders Hackathon 2026 · Build Creative track · solo build by Hanish**

Chinku asks one question: **"What do you need?"** You type, speak (Telugu, English, Hindi or a mix) or show a photo.
Chinku plans the steps and does the work: reads photos and documents, searches the web, **makes real phone calls**
with an AI voice agent, emails anyone, sets reminders, compares live options, and **follows up on promises** until the
task is done. Nothing is emailed, called, added to a cart or booked without your one tap. Chinku never pays.

> *"Equal answers the calls that come to you. Chinku makes the calls, sends the mails, and follows up until it's done."*

The app UI and all of Chinku's messages are available in **English, తెలుగు, हिन्दी and Telugu-English mix**. A translation
that changes any number is rejected in code, and the English original is shown instead.

## Evidence — `eval/results.md` (generated by `python -m eval.report`)

- **Exact transcription:** 0.8% word error rate for Chinku vs 17.5% for the same model with a plain prompt (13 pages,
  SIMULATED handwriting fonts incl. Telugu). 12 of 13 pages were copied exactly.
- **Planning:** 22 requests (English / Telugu / Hindi / mixed): 22/22 correct steps, 22/22 key fields,
  **0 wrong-action plans** (caveat: requests written by the builder, not a hold-out set).
- **Call extraction:** 12 calls (5 real): field accuracy on par with a plain prompt; **0 wrong-confirmed vs 1** for the baseline.
- **Persistence:** live server restarted mid-task → the same pending approval was still there (back in 3.2 s).

## How it works

```
capture (text · voice · photo · PDF · phone call)
  → transcribe (gpt-4o-transcribe, vocabulary from your memory)
  → plan (gpt-5.5, structured output: steps of fixed tools)
  → approval gate (in CODE: email, call, cart, reminder call — whatever the plan says)
  → tools → result cards → promises → follow-up
```

| Layer | What | Where |
|---|---|---|
| Planner + executor | One request → many tool steps; refs between steps; approval gate; never-silent errors | `app/chinku/planner.py`, `executor.py` |
| Tools | analyze, transcribe_image, search, map, call, draft/send email, remind (+ reminder calls), remember/recall, compute, find_support, promise/follow-up, scam_check, compare, recipe/shop_list/cart_add, trip_plan, connect_me | `app/chinku/tools.py` |
| Connected services | `ProviderAdapter` + `Offer` + ranking in code (cheapest / fastest / earliest; unknown price never ₹0) | `app/chinku/adapters/` (`kiwi.py` LIVE, `swiggy.py` LIVE, `rides.py` DEMO) |
| Phone calls | OmniDimension voice agent, one generic agent + per-call brief; answers extracted with evidence quotes | `app/engine/`, `app/voice/omni.py` |
| Exactness | Money, dates, rankings, pack sizes, official-domain check, night-time call rule — all code, with tests | `tests/` (123 tests) |
| App | Chinku App (`/app?key=…`), mobile first; Leaflet map; 🔊 Listen (OpenAI TTS) | `app/web/app.html` |
| State | DynamoDB via EC2 instance role; idempotent sends/calls; restart-safe | `app/store/dynamo.py` |

## Safety rules (enforced in code)

- Approval before anything leaves the device. A second "yes" never sends or adds twice.
- Memory never stores OTPs, passwords, card / bank / ID numbers.
- No calls between 9 PM and 8 AM to numbers you haven't saved (only people who agreed).
- Swiggy: checkout, payment and clearing the cart are blocked in code; adding merges with your cart.
- Every call opens "I'm an AI assistant calling on behalf of …"; never shares OTPs, never agrees to pay.

## Run it

```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt   # Windows; use .venv/bin on Linux/macOS
cp .env.example .env            # OpenAI, OmniDimension, Gmail app password, CHAT_KEY …
python -m pytest -q             # all tests mock every external service
uvicorn app.main:app --reload   # open http://localhost:8000/app?key=<CHAT_KEY>
python -m eval.make_pages && python -m eval.transcription_eval && python -m eval.planning_eval && python -m eval.report
python -m scripts.aws_deploy push   # tests must pass, then deploy to EC2 + health check
```
